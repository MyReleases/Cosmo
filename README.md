# Cosmo

Рабочее пространство продюсера: проекты, дизайн-документы, доски, встречи, задачи и совместная работа.

## ⬇️ Скачать

### 👉 [Открыть страницу последней версии](https://github.com/MyReleases/cosmo-releases/releases/latest)

На открывшейся странице найдите блок **Assets** и нажмите на файл **`Cosmo-Setup-….exe`** — это установщик (около 100 МБ). Остальные файлы в списке (`latest.yml`, `.blockmap`, `Source code`) скачивать не нужно.

## Установка

1. Запустите скачанный `Cosmo-Setup-….exe`.
2. Windows может показать синее окно «Система Windows защитила ваш компьютер». Нажмите **«Подробнее»**, затем **«Выполнить в любом случае»**. Окно появляется, потому что установщик пока не подписан сертификатом.
3. Пройдите мастер установки: выберите «Только для меня» и папку, нажмите «Установить».
4. При первом запуске Sunny спросит, как вас зовут.

Требуется Windows 10 или 11 (64-бит).

## Обновления

Скачивать установщик заново не нужно. Cosmo сам проверяет новые версии, загружает их в фоне, и Sunny предлагает перезапуститься. Проверить вручную: **Настройки → Общие → «Проверить обновления»**.

## Как присоединиться к проекту

1. Попросите у владельца проекта код приглашения (начинается с `cosmo-`).
2. В библиотеке нажмите **«Присоединиться»** и вставьте код.
3. Когда владелец подтвердит запрос, проект появится у вас в библиотеке.
